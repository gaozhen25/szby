# szby

本机上的工作项目源码汇总。已排除环境文件、真实 Cookie、浏览器数据、安装包和构建产物。

| 目录 | 内容 |
| --- | --- |
| er_platform_adapter | 多平台消息接入与轻回桌面连接器 |
| easyreply | 轻回前端 |
| gallery | 抖音 / 小红书分享链接解析与素材库 |
| starx-backend | StarX 内容采集后端 |
| starx-frontend | StarX 前端 |
| apispider | 采集接口服务 |
| apispider-js | 平台采集脚本 |
| mediacrawler | 本地使用的 MediaCrawler 工作副本 |
| boss | BOSS / 抖音 / 小红书私信工具 |
| card | 微信引流小程序 |

轻回管理后台、拾光账号服务、招聘工单和蜂巢设备控制的源码不在这台电脑上，因此没有放进本仓库。
