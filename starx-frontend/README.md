# startx-frontend

React version of the StarX MVP frontend.

## Run

```bash
npm install
npm run dev
```

Set backend API base if needed:

```bash
VITE_API_BASE_URL=http://127.0.0.1:10002/api/v1
```

## Auth

Demo account:

```text
email: demo@starx.ai
password: demo123
```

This ToB frontend only supports administrator-provisioned accounts. Public registration is disabled.
