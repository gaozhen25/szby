# 推荐选题星级展示设计

## 背景

当前选题中心的推荐选题卡片在左上角固定显示“⭐ AI 推荐”。本次需要恢复 Kim 分支的星级 UI，使推荐标识只显示星星，并让不同选题呈现不同星数。

## 设计

- 直接复用 `origin/Kim` 中的 `recommendStars(topic)` 逻辑，不改动卡片其他布局、筛选、收藏和创作流程。
- 当选题提供 `score`、`heat`、`recommendScore` 或 `recommend_score` 时，将有效正数换算并限制为 1–5 星。
- 当选题没有有效推荐分值时，以选题 `id` 为主、`title` 为备选生成稳定散列，显示 3–5 星。
- 推荐标识只渲染星星，不再显示“AI 推荐”；提示文案使用“推荐指数”。
- 不使用 `Math.random()`，避免 React 重渲染导致同一选题的星数反复变化。

## 测试与验收

- 更新选题中心预览测试，要求存在 Kim 的星级计算函数和纯星星渲染。
- 测试明确禁止恢复“⭐ AI 推荐”固定文案。
- 运行选题中心相关测试和前端完整测试，确认其他交互不受影响。

## 范围

本次只修改前端推荐星级展示及对应测试，不新增后端字段，不调整推荐算法，也不改动其他页面。
