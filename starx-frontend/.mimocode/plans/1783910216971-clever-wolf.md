## 第 2 步：数据看板页（DataDashboard.jsx）— 完全重写

**文件**: `src/pages/DataDashboard.jsx`  
**参考**: Image 4

### 目标布局

1. **顶部操作栏**: "数据看板 · {账号名}" + 副标题 + 账号选择下拉框 + 时间范围选择器（"近 30 天"）+ 更新时间文本 + "导出报告"按钮
2. **4 个指标卡片**: 曝光量 / 互动率 / 收藏数 / 涨粉，每个包含：
   - 标签（带 ℹ 图标）
   - 大数值 + 变化率（↑ +18% 绿色）
   - 右侧小型 sparkline 折线图（用纯 CSS/SVG 绘制简单波形）
3. **内容表现趋势**: 折线图卡片，展示曝光量+互动数的日期趋势（用 SVG `<polyline>` 绘制，不用第三方库）
4. **本周内容结构**: 饼图卡片（SVG `<circle>` + stroke-dasharray 实现），显示内容类型占比
5. **TOP 内容列表**: 表格/列表，排名+封面缩略图+标题+类型标签+浏览/收藏/互动数据
6. **运营洞察**: 右侧卡片列表，每条洞察有图标+标题+描述
7. **底部资源条**: 素材库数量 + AI 生图配额

### 需要的 CSS 新增
- `.dashboard-header` — 顶部操作栏
- `.dashboard-metrics` — 4列指标卡网格
- `.metric-card` — 指标卡片（含标签、数值、变化率、sparkline区域）
- `.metric-sparkline` — 小型图表区域（48px高）
- `.metric-change` — 变化率（绿色/红色）
- `.dashboard-charts` — 图表区域（2列：趋势图 + 饼图）
- `.dashboard-bottom` — TOP内容+运营洞察 2列
- `.insight-card` — 运营洞察卡片

### 临时方案
- sparkline 使用预定义的 SVG path 数据
- 折线图使用 SVG `<polyline>` + mock 数据
- 饼图使用 SVG `<circle>` + stroke-dasharray
- 不引入任何图表库

- **不引入新依赖**: 所有图表用纯 SVG 实现，不使用 recharts/chart.js
- **不修改 useStarxApp.js**: 保持数据层不变，只修改展示层

- **Mock 数据**: 图表数据用 mock 数据填充，与 API 数据源解耦
